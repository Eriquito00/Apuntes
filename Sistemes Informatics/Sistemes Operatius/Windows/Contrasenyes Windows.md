# Contrasenyes Windows
## Error usuari al cambiar la contrasenya
Podria ser que iniciem sessio al nostre usuari i no ens deixi utilitzar l'usuari quan obrim alguna cosa amb ell despres d'haber cambiat la contrasenya. Per arreclar aixo podem anar a la direccio del usuari com per exemple la seguent.

```
C:\Users\"(nom usuari)"\AppData\Local\Microsoft_Corporation
```

I tot el que estigui aqui dins ho esborrarem, aixo son arxius temporals que crea el dispositiu i quan fem un cambi de contrasenya podria ser que no ens deixi utilitzar l'usuari perque s'ha quedat amb una contraseña antiga i no ens permet entrar amb aquest usuari.
