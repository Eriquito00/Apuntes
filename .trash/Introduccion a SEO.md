# Introduccion a SEO
El SEO al final es una eina que utilitzen els motors de cerca per trobar la millor pagina web segons la cerca de l'usuari.
## SEO vs SEM
SEO: proporciona una resposta de qualitat, una pagina web que realment esta ben feta i encaixa de forma practicament exacta amb la cerca del usuari.

SEM: es una pagina web que proporciona el cercador segons certs pagaments a per exemple google ads, es a dir, pagar per sortir per sobre d'altres.
